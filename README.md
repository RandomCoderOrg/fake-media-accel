# fake-media-accel

Experimental bridge bringing Android MediaCodec acceleration to Linux applications running in PRoot.

Current VA-API status and probes: [docs/va-api.md](docs/va-api.md). Codec
checkpoints: [H.264](docs/h264.md), [VP9](docs/vp9.md), and
[AV1](docs/av1.md).

Setup: [proot-distro and uDroid Bash CLI](docs/setup-proot.md).
Application compatibility and end-to-end measurements:
[docs/applications.md](docs/applications.md).
